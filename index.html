Kompagni

Plateforme de prise de rendez-vous et d'ordonnancement intelligent pour les salons de toilettage animalier. Un backend NestJS piloté par un moteur de planification propriétaire, et deux applications Flutter — une pour les clients, une pour les professionnels.

⚠️ Les repos sont encore privés — le code est en plein nettoyage avant publication.

Pourquoi Kompagni ?

Janvier 2026

La genèse

Avant d'écrire une ligne de code, j'ai échangé avec une toiletteuse professionnelle pour comprendre le métier de l'intérieur. Rendez-vous annulés à répétition, agenda tenu à la main, durées et prix calculés au feeling selon la race ou le pelage : le problème était réel, précis, et jamais vraiment résolu — dans un marché du toilettage animalier par ailleurs en pleine expansion en France.

Jan. – Août 2026

Le code

Le développement démarre dans la foulée : une API NestJS pilotée par le Kairos Engine, qui calcule automatiquement durées et niveaux de difficulté, et deux applications Flutter — une pour les clients, une pour les salons. Huit mois de travail solo, en parallèle des études.

Août 2026

La mise en pause

Une première version stable est aujourd'hui codée et testable sur demande. Faute de temps pour aller plus loin pour le moment, le projet est mis en pause — la base est solide, prête à être reprise.

Le projet

Kompagni API

Backend NestJS 11 / Prisma 6 / PostgreSQL. Authentification Supabase, et le Kairos Engine : un moteur de calcul de durées, de difficulté animale et de verrouillage atomique de créneaux pour éviter les surréservations.

github.com/Nevenjbx/kompagni-api →

Kompagni Client

Application Flutter Web & Mobile pour les propriétaires d'animaux : recherche de salons, gestion des profils animaux, réservation en ligne avec estimation en temps réel.

github.com/Nevenjbx/kompagni →

Kompagni Pro

Application Flutter Web & Mobile pour les salons et leurs équipes : planning interactif, supervision des apprentis, règles tarifaires sur-mesure et configuration avancée.

github.com/Nevenjbx/kompagni →

Le parcours de réservation

Le wizard de prise de rendez-vous côté client, de bout en bout : choix du salon et de la prestation, sélection de l'animal, puis créneau disponible avec durée et tarif estimés en temps réel par le Kairos Engine.
